# VirgoXbeast-Perf

Universal Android Gaming Optimization Module by VirgoYT.

## Highlights
- **Butter Pacing Engine**: System-level frame pacing, touch optimization, and governor configuration.
- **Hardware Telemetry**: Real-time CPU, GPU, temperature, and charging status via KernelSU/APatch/Magisk WebUI.
- **Zero Game File Touches**: All tweaks target kernel and OS sysfs nodes.

## Installation
Flash `VirgoXbeast-Perf.zip` via Magisk, KernelSU, or APatch.
